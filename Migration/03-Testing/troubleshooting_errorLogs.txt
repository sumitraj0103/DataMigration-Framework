The error means that the user or service principal running the data transfer operation does not have EXECUTE permission on the stored procedure sp_GetFolderMappingSourceFolder_V2 in the DMAP database.
This is a SQL Server security error (Error 229), indicating a lack of required permissions to run the stored procedure.
To resolve this, a database administrator should grant EXECUTE permission on the stored procedure to the user or service principal being used for the data transfer.

This was resolved when access permissions to execute stored procedure were granted to the ADF Service Principal.
