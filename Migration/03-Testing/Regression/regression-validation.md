# Regression Validation

## Purpose

This document records the execution of reusable regression validation across Azure Data Factory (ADF) pipelines following pipeline, configuration or infrastructure changes.

Regression validation verifies that previously validated functionality continues to operate correctly and that implemented changes have not introduced unintended impacts.

The reusable regression validation definitions are maintained in **regression-test-catalogue.md**.

Deployment, technical and functional validation should be successfully completed before regression validation begins.
